# The issues, counted once

Every issue in this record, each listed once. An issue MuJoCo's users report and one Senua AI's Measure found are the
same issue when they are the same departure; the sources column names both. Every count on the front page comes from
this list. The reports, with their sources, are in [the reported problems](known-issues.md) (M1 to M16); Senua AI's
measurements and causes are in [the findings](findings.md) (F1 to F19).
