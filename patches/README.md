# Patches

Corrections to MuJoCo found by this record. A patch is designed and held to the five checks as a probe (required,
correct, nothing else gets worse, safe when off, the solver keeps converging) under `in_design/`; it is validated
only when a registered study states its rules and plays it once, as in the first deep dive. A validated patch is kept
here, beside the copy under `in_design/` that its registration names (the same file). Each patch is off unless its
switch is set, and with the switch unset the patched MuJoCo plays byte for byte as the release does.
